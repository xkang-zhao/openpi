## 二、P0 问题详情与修复方案

### 1. 仓库卫生：垃圾文件入库

```bash
# 已确认入库
git ls-files | grep -E "\.DS_Store|\.pdf"   # → .DS_Store, 2504.16054v1.pdf

# 修复：从 git 移除（保留本地文件）
git rm --cached .DS_Store 2504.16054v1.pdf
# .gitignore 追加：
.DS_Store
*.pdf
```

> 上游遵守：`third_party/` 用 submodule，模型权重走 `gs://openpi-assets`，仓库内不放二进制。16MB PDF 应该放到 docs/ 或 wiki，不该进 git 历史。

### 2. 配置硬编码：个人路径泄漏

`src/openpi/training/config.py` 中 `pi05_auto_stack` 配置：

```python
repo_id="/zxk/my_openpi/auto_stack",                    # ← 个人路径
assets=AssetsConfig(asset_id="/zxk/my_openpi/auto_stack"),  # ← 个人路径
weight_loader=CheckpointWeightLoader("/zxk/my_openpi/pi05_base/params"),  # ← 个人路径
```

修复原则（参考上游 `gs://openpi-assets/...` 惯例）：
- **数据集**：上传到 HuggingFace / 共享 NAS，用 `repo_id="team/auto_stack"` 或环境变量 `$OPENPI_DATA_HOME`
- **权重**：走 `gs://openpi-assets` 或共享存储，配置里只写逻辑路径
- 配置是**团队资产**，不允许出现个人用户名

## 三、P1 问题详情与修复方案

### 3. 补测试：`auto_stack_policy` 零覆盖

上游惯例：每个 policy 都有 `*_test.py`（如 `libero_policy` 在 `policies/policy_test.py` 中测试）。建议新增 `src/openpi/policies/auto_stack_policy_test.py`：

```python
import numpy as np
from openpi.policies import auto_stack_policy


def test_make_auto_stack_example_shape():
    example = auto_stack_policy.make_auto_stack_example()
    assert example["observation.state"].shape == (7,)
    assert example["observation.images.top_camera"].shape == (3, 224, 224)
    assert example["observation.images.top_camera"].dtype == np.uint8


def test_auto_stack_inputs_outputs():
    transform = auto_stack_policy.AutoStackInputs(model_type="pi0")
    data = {
        "observation.state": np.zeros(7),
        "observation.images.top_camera": np.zeros((3, 224, 224), dtype=np.uint8),
        "observation.images.wrist_camera": np.zeros((3, 224, 224), dtype=np.uint8),
        "action": np.zeros((10, 7)),
        "task": "stack the block",
    }
    out = transform(data)
    assert out["state"].shape == (7,)
    assert set(out["image"]) == {"base_0_rgb", "left_wrist_0_rgb", "right_wrist_0_rgb"}
    assert out["image_mask"]["right_wrist_0_rgb"] is np.False_
    assert out["actions"].shape == (10, 7)
    assert out["prompt"] == "stack the block"
```

### 4. 提交规范

- **Git 身份**：`git config user.name/email` 统一为团队身份（当前是 `xk@mac`）
- **提交信息模板**（Conventional Commits，上游也在用）：
  ```
  feat: add AutoStack adapter for UR10e
  fix: correct norm stats path in auto_stack config
  docs: document save_weights_only semantics
  ```
- **提交粒度**：`feat` + `fix` 拆开，`"修改配置"` 这种信息等于没写

## 四、P2 观察项：`save_weights_only` 双轨一致性

改动本身设计合理（推理 checkpoint 不需要 optimizer/train_state），但需验证：

1. **JAX 路径**：`checkpoints.py` 已正确跳过 `train_state` 的 handler
2. **PyTorch 路径**：`train_pytorch.py` 跳过 optimizer/metadata 保存 —— 需确认 **resume 逻辑同样检查了 `save_weights_only`**（否则 resume 时读到不完整的 checkpoint 会静默失败）
3. 建议在 `TrainConfig.validate()` 中已加冲突检查的基础上，补一个**恢复训练路径的集成测试**
