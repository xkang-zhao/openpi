## AutoStack 数据链路分析（关键发现）
- pi05_auto_stack 配置使用 LeRobotAutoStackDataConfig，其 repack `"task": "prompt"` 把 PromptFromLeRobotTask 注入的 prompt 重命名为 task，AutoStackInputs 的 `if "task" in data` 才能命中
- 数据集本身没有 "task" 键，是 repack 生成的 → 训练正常
- pi0_auto_stack 用 SimpleDataConfig，无 repack，若数据集无 "task" 键会报 ValueError("Prompt is required")，建议改用 LeRobotAutoStackDataConfig
- pi05_auto_stack 当前参数: action_horizon=50, batch_size=32, 本地权重 /zxk/my_openpi/pi05_base/params, lr_schedule 自定义(warmup 10k, peak 5e-5, decay 1M steps), ema_decay=0.999, save_interval=50, save_weights_only=True

## 配置审查结论 (18:35)
- pi05_auto_stack 配置健康: action_dim=32(默认)匹配 pi05_base 权重; 与官方 pi05_libero 的 lr/ema 参数一致; 但 save_weights_only=True 意味着无法 --resume 续训(restore_state 需要 train_state)
- pi0_auto_stack 有两个问题:
  1. 致命: action_dim=7 与 pi0_base 权重(action_dim=32)形状不匹配, train.py:76 check_pytree_equality(check_shapes=True) 会抛错, 训练无法启动. 官方 pi0_libero 也是保持 action_dim=32 靠 PadStatesAndActions 解决
  2. SimpleDataConfig 无 repack "task": "prompt", prompt 链路断
  - 修复方案: 改 Pi0Config(action_horizon=10) 去掉 action_dim=7 + 换 LeRobotAutoStackDataConfig
